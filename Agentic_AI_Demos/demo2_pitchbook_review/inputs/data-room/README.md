# GraspLoop AI — data room (FICTIONAL)

All data is invented for a teaching demo.

`kpi-monthly.csv` — one row per month, Sep 2025 – Sep 2026.

| Column | Meaning |
|---|---|
| paying_customers / pilot_customers_unpaid | Customers on paid contracts vs. free pilots |
| robots_live_paying / robots_in_unpaid_pilots | Robots billed at $3,500/month vs. robots in free pilots |
| mrr_usd | Monthly recurring revenue from paying robots |
| booked_arr_incl_pilots_usd | (paying + pilot robots) × $3,500 × 12 — includes unpaid pilots |
| picks_millions | Picks per month, all robots |
| pick_success_mixed_sku_pct | Fleet-wide pick success on mixed SKUs |
| pick_success_best_site_single_sku_pct | Best single site, single-SKU lanes |
| teleop_interventions_per_1k_picks | Remote-operator interventions per 1,000 picks |
| gross_margin_pct | Monthly gross margin |
| opex_usd / sales_marketing_usd | Monthly operating expense / of which sales & marketing |
| net_burn_usd / cash_end_usd | Monthly net cash burn / month-end cash |
| headcount | Employees at month end |
| sep2025_cohort_mrr_usd | MRR from the 3 customers that were paying in Sep 2025 |
