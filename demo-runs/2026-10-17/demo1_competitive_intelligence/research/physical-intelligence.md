## 2 Technology
- **π*0.6 / RECAP** combines demonstrations, corrective teleoperation and autonomous practice. PI reports more than twice the throughput on some difficult tasks and lower failure rates; these are company-reported experimental results, not a universal production guarantee. *(2025-11-17)* [4]
- **π0.7** adds multimodal conditioning and company-reported compositional generalization across tasks and robot platforms. Its release is a research/model milestone, not evidence that every robot can perform every task. *(2026-04-16)* [5]
- **Pi API beta** provides managed fine-tuning and hosted inference. The launch points to public π0/π0.5 code while offering newer models through the beta; this does not establish open weights for the latest API models. *(2026-10-13)* [6]
